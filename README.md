\# SistemMonitor



A Windows desktop application for real-time system monitoring.



\## Features



\- Real-time CPU usage

\- Real-time GPU usage

\- CPU \& GPU temperature monitoring

\- RAM usage monitoring

\- Internet usage monitoring

\- Windows error log viewer

\- Remote monitoring using QR Code(Works over the same Wi-Fi or LAN network)



> The application interface is currently available only in Turkish.
